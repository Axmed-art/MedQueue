# MedQueue

Локальный прототип записи к стоматологу на HTML, Python и SQLite.

## Запуск

1. Установите Python 3.10 или новее.
2. Запустите `start_medqueue.bat` двойным щелчком из Проводника. Скрипт сам перейдёт в папку проекта и запустит сервер.
3. Оставьте открытым чёрное окно сервера и откройте <http://127.0.0.1:8000> в браузере.
4. Панель клиники находится по адресу <http://127.0.0.1:8000/admin.html>.

Также сервер можно запустить вручную из корня проекта:

   ```powershell
   python server.py
   ```

Остановить сервер: нажмите `Ctrl+C` в окне, где он запущен. При первом запуске сервер создаст `medqueue.db` и добавит демонстрационные слоты на ближайшие дни. База хранится локально и исключена из Git.

Если сервер не запускается, убедитесь, что установлен Python 3 и порт 8000 не занят другой программой.

## API

- `GET /api/slots` — свободные слоты; `?all=1` включает занятые слоты для панели.
- `GET /api/slots/{id}` — сведения о конкретном слоте.
- `POST /api/slots` — добавить слот.
- `DELETE /api/slots/{id}` — удалить свободный слот.
- `GET /api/appointments` — список записей.
- `POST /api/appointments` — создать запись на свободный слот.

Сервер привязан к `127.0.0.1` и предназначен для локальной демонстрации. Панель не имеет авторизации и не должна публиковаться в интернет.
