# MedQueue

Локальный прототип записи к стоматологу на HTML, Python и SQLite.

## Запуск

1. Установите Python 3.10 или новее.
2. В корне проекта выполните:

   ```powershell
   python server.py
   ```

3. Откройте <http://127.0.0.1:8000>.
4. Панель клиники находится по адресу <http://127.0.0.1:8000/admin.html>.

При первом запуске сервер создаст `medqueue.db` и добавит демонстрационные слоты на ближайшие дни. База хранится локально и исключена из Git. Остановить сервер можно сочетанием `Ctrl+C`.

## API

- `GET /api/slots` — свободные слоты; `?all=1` включает занятые слоты для панели.
- `GET /api/slots/{id}` — сведения о конкретном слоте.
- `POST /api/slots` — добавить слот.
- `DELETE /api/slots/{id}` — удалить свободный слот.
- `GET /api/appointments` — список записей.
- `POST /api/appointments` — создать запись на свободный слот.

Сервер привязан к `127.0.0.1` и предназначен для локальной демонстрации. Панель не имеет авторизации и не должна публиковаться в интернет.
