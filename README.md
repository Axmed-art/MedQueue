# MedQueue

MedQueue — сайт для записи к стоматологу в Алматы. Пациент может найти клинику, выбрать свободное время и посмотреть свои записи в личном кабинете. Клиника подаёт заявку на сайте, а после одобрения получает доступ к расписанию.

Проект подготовила команда **MedLink**: А. Нұрболат, Д. Самира и Л. Артем.

Сайт: https://medqueue-hs9r.onrender.com  
Репозиторий: https://github.com/Axmed-art/MedQueue

## Как запустить

Для запуска нужен Python 3.10 или новее. В Windows откройте `start_medqueue.bat`. Когда в окне появится сообщение о запуске сервера, откройте <http://127.0.0.1:8000>.

Либо откройте папку проекта в терминале и выполните:

```bash
python server.py
```

Чтобы остановить сервер, нажмите `Ctrl+C`. При первом запуске рядом с `server.py` создаётся файл `medqueue.db` — в нём хранятся аккаунты, клиники, расписание и записи.

## Что можно посмотреть

- На главной странице — короткое описание сервиса.
- В разделе «Клиники» — список клиник, поиск и доступное время.
- В «Кабинете» — регистрация пациента или клиники и вход в аккаунт.
- В кабинете клиники — управление расписанием после одобрения заявки.
- В панели владельца — заявки клиник и общая информация по сайту.

Для локального показа панель владельца доступна через «Кабинет». Данные для входа: `admin@medqueue.local`, пароль `MedQueue123!`. Это учебная учётная запись для запуска на своём компьютере; на публичном сайте используйте настройки из раздела ниже.

## Сайт на Render

Render собирает сайт из GitHub после отправки изменений в подключённую ветку, если в настройках сервиса включён автоматический деплой.

Для входа владельца на Render нужно добавить в настройки сервиса переменные `SITE_ADMIN_EMAIL` и `SITE_ADMIN_PASSWORD`.

Сейчас база данных — обычный SQLite-файл. На бесплатном Render он может очиститься после перезапуска или нового деплоя, поэтому не рассчитывайте на постоянное хранение регистраций и записей на опубликованной версии.
